# The catalogue of mutations: one entry per line, five fields separated by TAB.
#
#   id <TAB> file to mutate <TAB> exact text to replace <TAB> text that replaces it
#        <TAB> tests of tests/ that must fail when the mutation is applied
#
# The text to replace has to appear EXACTLY ONCE in the file: a text that appears nowhere
# changes nothing and proves nothing, and one that appears twice is ambiguous. The runner
# refuses both, so an inert entry cannot sit in this file unnoticed. A text holds no TAB:
# the line carries exactly four, and a fifth would move every field after it.
#
# The tests named by an entry are the ones that must notice when it is applied. Every
# entry below was checked: with the mutation applied at least one of the named tests
# fails, and with the tree unmutated every one of them passes.
#
# WHAT IS EXCLUDED, AND WHY
#
# The suites are run over a copy of the tree made with `git archive HEAD`, which carries
# no git metadata. A suite that needs the history of the repository is red there whatever
# the mutant is, and counting it as a kill would be a kill that never happened. These
# are excluded, and no entry below names them:
#
#   tests/ci/suites/check-suite-completeness.test.sh
#       It is the runner of the suites: it takes the list of suites as its arguments, so
#       it cannot be run on its own, and it reads HEAD^1 to decide whether a pull request
#       may narrow the suite set. A copy made with `git archive` has no HEAD^1.
#
#   tests/quality/check-editorconfig.test.sh
#       The gate it covers enumerates the files with `git ls-files`. A copy made with
#       `git archive` is not a repository, so the walk finds nothing, and a gate that
#       inspected nothing is the failure this gate exists to catch.
#
# No suite of this repository needs the network or a tool that is absent here: the
# watchers that fetch from GitHub are tested against a fake curl on PATH, and the
# manifest tests need jq and python3, which are installed. The scripts that would need
# reprepro, brew or scoop are not part of this repository.
#
# Run: tests/mutation/run-mutations.sh [--list] [<id>]
